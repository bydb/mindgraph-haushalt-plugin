# Haushalt — Plugin für MindGraph Notes

Nebenbuch für Einrichtungen, deren Träger offiziell bucht und bezahlt (z. B. Medienzentren, Schulen, Vereine mit Verrechnungskonto beim Kreis):

- Haushaltsstellen in zwei Ebenen (Hauptgruppe mit Ansatz, Unterstellen zum Buchen), durchlaufende Posten
- Buchungen mit Beleg (PDF im Vault), Status vorgemerkt → angeordnet → vom Kreis gebucht
- Haushaltsüberwachung: Ansatz, Änderungen (Übertrag, Nachtrag, Umschichtung, Sperre), Ist, frei
- Guthaben beim Träger: nach eigenen Buchungen und vom Träger bestätigt
- Abgleich mit der Liste des Trägers
- Jahresabschluss mit Übertrag der Reste
- Bericht als Excel und PDF im Layout einer klassischen Haushaltstabelle, Buchungsliste als CSV
- Import aus Quicken (QIF) und aus der bisherigen Excel-Tabelle

Alles bleibt lokal im Vault. Keine KI, kein Netz.

Entwicklung: `npm install`, `npm test`, `npm run build`.
